# Results

Raw benchmark output, committed for reproducibility and transparency.

- `<db>.json` — full workload results for a platform (latency p50/p95, mixed
  throughput, footprint). Produced by `python -m bench run --db <db>`.
- `<db>.ingest.json` — ingest throughput (nodes/s, rels/s, wall time).
  Produced by `python -m bench load --db <db>`.
- `matrix.csv`, `ingest.csv`, `mixed.csv`, `matrix.md` — generated by
  `python -m bench report`; these are regenerable and gitignored.

Dry-run (`mock.*`) outputs and generated tables are gitignored. The real
per-platform results are committed so the numbers can be audited.
